# resources/bin

שים כאן את `uxplay.exe` ואת קובצי ה-DLL שמגיעים איתו (מתוך build של UxPlay ל-Windows).

- בזמן פיתוח (`npm run dev`) האפליקציה מחפשת כאן את `uxplay.exe`.
- ב-build (`npm run dist`) כל התיקייה הזו נארזת לתוך המתקין, תחת `resources/bin`.

הקבצים הבינאריים לא נשמרים ב-git (ראה `.gitignore`).

UxPlay: https://github.com/FDH2/UxPlay (רישיון GPL-3.0)
